# Portfolio — Paul DAVID

Portfolio personnel de **Paul DAVID**, développeur web (Next.js, JavaScript, C#) et ancien ingénieur du son.  
Étudiant à **Epitech**, actuellement en recherche d’**alternance**.

## À propos

Après plusieurs années en studio — dont l’album *Jefe* de Ninho, certifié diamant et enregistré / mixé en grande partie par moi — je me consacre au développement web. Ce site rassemble mes projets techniques, mon parcours musical et un point de contact.

## Fonctionnalités

- Page unique immersive : intro, projets web, musique, contact
- Carrousel de projets avec aperçu mobile (mockup iPhone) et descriptions détaillées
- Animations GSAP (ScrollTrigger, texte découpé, hover)
- Fond Aurora en WebGL (OGL)
- Scroll fluide (Lenis)
- Copie d’email au clic, liens sociaux et téléchargement du CV
- Responsive (desktop + mobile)

## Stack

- **Next.js 16** / **React 19**
- **Tailwind CSS 4**
- **GSAP** + ScrollTrigger
- **Lenis** (smooth scroll)
- **OGL** (fond Aurora)
- **SplitType** (animations de texte)
- **Vercel Analytics**

## Lancer le projet

Prérequis : Node.js 18+

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # build de production
npm start       # serveur de production
npm run lint    # lint
```
